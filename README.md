# Bank Management System - bankDB

A simple Bank Management System built using Python and MySQL. This is my AI & DS academic project.

### Features
- Create new bank account
- Deposit and Withdraw money
- Check account balance
- View transaction history

### Tech Stack
- Python
- MySQL
- mysql-connector-python
- python-dotenv

### How to run
1. Clone the repo: `git clone https://github.com/arunaammu509-ui/bankDB.git`
